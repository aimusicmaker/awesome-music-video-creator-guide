# Contribute a recipe that helps someone finish

[Home](README.md)

Submit one original recipe or a focused correction. Include the intended result, required inputs, exact prompt, actual tool/settings if tested, an edit plan, and one useful failure/fix. State **untested brief** when there is no generated result.

For a demo, identify its creator and original source. Share only media you can contribute, with the applicable license or permission. Do not copy a full third-party prompt, download a creator’s song into this repository, or present an external video as your own output.

Keep new content practical and readable. Avoid unverifiable rankings, views, unlimited/free promises, and provider capabilities inferred from a model name. Date any live tool or pricing observations. Keep homepage claims and recipe counts accurate.

Original contributions are submitted under the repository’s MIT License unless an asset is explicitly documented otherwise. Add media provenance to [assets/README.md](assets/README.md). Do not remove the third-party exceptions.

Run `python3 scripts/check_content.py` before a pull request. Preview changed Markdown at desktop and phone widths. Mechanical checks do not establish generated-video quality.
