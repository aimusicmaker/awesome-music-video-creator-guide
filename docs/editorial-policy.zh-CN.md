# 谁在维护，以及如何核对内容

[返回首页](../README_ZH.md) · [English](editorial-policy.md) · [来源记录](sources.md) · [反馈问题](https://github.com/aimusicmaker/awesome-music-video-creator-guide/issues/new/choose)

本仓库由 **MusicMaker 团队**通过 [aimusicmaker GitHub 组织](https://github.com/aimusicmaker)维护，帮助初学者规划并完成音乐短片。MusicMaker 是我们的自有品牌；这里的品牌工具与案例推荐不属于独立第三方背书。

官方模型栏目优先选择 MusicMaker 已有工具页面的模型，并同时提供模型厂商资料与品牌入口。这是有明确范围的学习资料库，不是全市场模型排名。厂商公布的能力，不代表品牌入口提供全部选项。

## 三类证据，各自说明什么

| 证据类型 | 可以核对的内容 | 不能据此推断的内容 |
|---|---|---|
| **本仓库已制成** | [16 秒剪辑成片](../starter-kit/night-train-edit-demo.mp4)、[原创练习音乐](../starter-kit/practice-beat-120bpm.wav)、[音乐生成脚本](../scripts/make_practice_audio.py)和[练习包](../starter-kit/README.md) | 成片是静态图推拉、裁切与配乐，不是场景内部的生成动画，也不是 MusicMaker 模型实测 |
| **已核对来源或可用性** | [来源记录](sources.md)、[官方案例记录](official-cases.json)和[品牌案例](brand-examples.md)中的核对日期、公开表单、素材与播放记录 | 能打开页面或播放成片，不等于复现了生成过程、测试了某个账户，或比较了输出质量 |
| **创作提案，尚未生成** | 可复制提示词、分镜与改编建议，包括首页的彩虹山谷和人像演唱两套教程 | 这些是练习方案，不是原作品生产提示词或已验证的模型结果；尚无完整生成实测记录 |

较早制作的列车剪辑示例可以直接用于练剪辑，但不能作为首页两套新教程已生成成功的证据。

## 内容怎样制作

我们使用 AI 工具辅助写作、翻译、原创插图、代码和审阅。模型审阅只用于帮助查错，不等于真人专家背书。未记录的专业资历、独立评测、母语审校或制作经验，不作为本库的宣传依据。

模型事实尽量链接厂商原始资料，并区分厂商说明、界面可见选项、创作者自述和本库练习建议。引用案例保留来源和署名；原创图片提示词及素材使用范围见[素材说明](../assets/README.md)。仓库的 MIT 许可证不覆盖外部作品。

今后发布生成实测时，应记录日期、实际工具与版本、输入素材及使用权限、完整提示词、设置、输出和失败修正。在这些记录齐备前，练习仍标为未实测。检查脚本通过，只能证明脚本覆盖的检查项通过。

## 品牌链接与商业关系

本库介绍自有品牌 MusicMaker；读者使用其服务可能带来品牌商业收益。仓库中的 MusicMaker 链接没有额外添加联盟推广参数。这不代表网站没有统计、Cookie、归因或其他商业安排。[联盟推广计划](https://musicmaker.im/affiliate-program/)用于邀请潜在合作伙伴，具体条件以当前条款为准。有免费入口，不代表所有功能、模型或生成素材都免费。

## 更新、语言与纠错

来源核对均以记录中的日期为准，不作永久有效的保证。旧观察明确标为历史记录；当前首页内容以所链接的清单为准。仓库提供 15 种语言及独立手机版；详细文档主要为英文或简体中文。各版本的维护与审校状态见[语言说明](../i18n/README.md)。

发现失效链接、事实错误或翻译问题，可使用[简单纠错表单](https://github.com/aimusicmaker/awesome-music-video-creator-guide/issues/new/choose)。请提供所在页面、具体语句或链接；有依据时附上来源。反馈是公开的，不要填写账户密码、个人信息或付费文件。维护团队通过 GitHub 问题单处理反馈，修改可从提交历史追踪；不承诺固定回复时限。
