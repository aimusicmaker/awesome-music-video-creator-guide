# Who maintains this guide and how we check it

[Home](../README.md) · [中文](editorial-policy.zh-CN.md) · [Source records](sources.md) · [Report an issue](https://github.com/aimusicmaker/awesome-music-video-creator-guide/issues/new/choose)

This repository is maintained by the **MusicMaker team** under the [aimusicmaker GitHub organization](https://github.com/aimusicmaker). It helps beginners plan and finish short music videos. MusicMaker is our own brand: its tools and examples are first-party recommendations, not independent endorsements.

The official-model selection prioritizes models with an existing MusicMaker tool page. Each model links to its maker's documentation and the corresponding brand entry. This is a scoped learning collection, not a comprehensive market ranking. An official capability does not prove that every option is available through the brand interface.

## What each kind of evidence means

| Evidence | What you can verify | What it does not establish |
|---|---|---|
| **Made in this repository** | [16-second completed editing example](../starter-kit/night-train-edit-demo.mp4), [original practice audio](../starter-kit/practice-beat-120bpm.wav), [audio generator](../scripts/make_practice_audio.py) and [practice kit](../starter-kit/README.md) | The example pans and crops a still image; it is not a generated-motion result or a MusicMaker model test |
| **Source or availability checked** | Dated notes for official documentation, public input forms, linked artwork and media playback in [sources](sources.md), [official cases](official-cases.json) and [brand examples](brand-examples.md) | Loading or playing a published example is not reproducing its generation, testing an account, or comparing output quality |
| **Proposed; not generated here** | Copyable prompts, shot plans and adaptation notes, including the rainbow-valley and portrait-singing homepage tutorials | These are exercises, not recovered production prompts or proven model outputs; no end-to-end generation result is claimed |

The older train editing example is available for immediate editing practice. It must not be presented as proof that the two newer homepage tutorials have been generated successfully.

## How content is prepared

AI tools assist with writing, translation, original illustrations, code and review. Model-based review is an editorial aid, not a human expert endorsement. We do not claim named professional credentials, independent benchmarking, native-speaker approval or production experience that is not documented.

We link factual model claims to primary sources and distinguish the model maker's description, a visible interface option, a creator's claim and our own exercise. Public examples retain source links and credits. Original image prompts and media boundaries are recorded in [asset notes](../assets/README.md); external material is not covered by the repository's MIT license.

For any future generation test, the record should include the date, actual tool and version, inputs and rights, complete prompt, settings, output, and failures or corrections. Until those records exist, the exercise remains untested. A script passing only establishes the checks described by that script.

## Updates, languages and corrections

Source checks are dated in their records, not presented as permanent guarantees. Historical observations are labeled as historical; the current homepage catalog is maintained in the linked manifests. Fifteen language editions and separate mobile editions are available; detailed documents are mainly English or simplified Chinese. See [language maintenance and review status](../i18n/README.md).

Use [the correction forms](https://github.com/aimusicmaker/awesome-music-video-creator-guide/issues/new/choose) for broken links, factual issues or translation problems. Include the page, the sentence or link, and a supporting source if available. Reports are public: omit account credentials, personal data and paid files. Maintainers review reports through GitHub issues and changes remain visible in commit history; no response time is promised.
