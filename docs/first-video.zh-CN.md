# 从零做一支 16 秒音乐短片

[返回首页](../README_ZH.md) · [下载练习包](../starter-kit/README.md) · [English](first-video.md)

先用一段短音乐完成整个过程：准备素材、剪辑、加标题、导出。熟悉之后，再替换成自己的歌。

[下载完成的静态图剪辑示例](../starter-kit/night-train-edit-demo.mp4)。它使用同一段音乐和四镜头节奏，只对图片进行推拉与裁切，不是场景内部的生成动画。

## 1. 下载音乐与分镜表

打开[练习音乐](../starter-kit/practice-beat-120bpm.wav)和[分镜表](../starter-kit/shot-list.csv)，在 GitHub 文件页点击 **Download raw file** 下载。也可以在仓库首页点 **Code → Download ZIP**，一次下载整个仓库并解压。

音乐是为本仓库原创合成的 16 秒纯音乐，不是 MusicMaker 的生成结果。每分钟 120 拍，共 32 拍；每 4 拍是一个小节，每小节 2 秒。这是一段用来练习节奏与剪辑的简单配乐。

## 2. 选一个入口，做出四个短镜头

两条路线使用同一份[四镜头提示词](../starter-kit/train-shot-prompts.md)，最后都剪成 16 秒。先完成一个镜头，检查后再继续，避免一次生成四段却发现风格不合适。

| 你希望怎样开始 | 模型官方工具 | MusicMaker 品牌工具 |
|---|---|---|
| 文字生成夜车等环境镜头 | [Hailuo 的 MiniMax H3](https://hailuoai.video/zh-Intl/tools/minimax-h3)：选择 H3 和文字生成模式 | [MusicMaker 短片工具](https://musicmaker.im/free-short-music-video-generator/)：填写场景提示词，选画面比例 |
| 从自有封面做动画 | 同一官方入口，选择图片或首尾帧模式 | 同一品牌入口，按页面要求提供 Start Frame 与 End Frame |
| 人像配合已有歌声 | 官方 H3 的多素材参考路线，见下方演唱步骤 | [MusicMaker 音乐视频](https://musicmaker.im/ai-music-video-generator/)：音乐、人物图、动作描述 |

**怎样把官方与品牌联系起来？** MiniMax 是 H3 的模型开发方；MusicMaker 短片页明确标注使用 H3，为短音乐画面提供了简化入口。两者操作界面、额度和输出规格不同。MusicMaker 演唱页没有标明示例采用的模型，这里把它作为相同创作目标的另一种工具，不将它归为 H3 成片。

### 路线 A：用模型官方工具生成

1. 打开 [Hailuo H3](https://hailuoai.video/zh-Intl/tools/minimax-h3)，进入创作页，按页面要求登录。选择 **MiniMax H3**，本练习选文字生成视频；不用上传音频。
2. 从[分镜提示词](../starter-kit/train-shot-prompts.md)复制 **A 镜头的完整段落**。它应包含同一节车厢、雨夜、暖灯以及本镜头的观察角度。不要把四个镜头一次粘进去。
3. 画面选 **9:16**，先生成 **5 秒**。分辨率以账户当前能选的档位为准；先检查构图和动作，再考虑更高规格。
4. 生成后看两遍：第一遍看构图，第二遍只看窗框和灯具是否突然变形。下载合格片段为 `A.mp4`。保留实际输入与设置，便于再次生成。
5. 按同样方法生成 B、C、D，保留地点和灯光，只改变镜头重点。生成声音不是本练习的最终配乐，稍后统一静音。

官方界面用法依据 [Hailuo 的操作说明](https://hailuoai.video/zh-Intl/tools/minimax-h3)，能力边界见 [MiniMax 发布说明](https://www.minimax.io/blog/minimax-h3)。账户可用功能可能不同，本教程没有代替读者提交生成任务。

### 路线 B：用 MusicMaker 生成

1. 打开 [MusicMaker 短片工具](https://musicmaker.im/free-short-music-video-generator/)，将 **Aspect Ratio** 设为 **9:16**。
2. 纯文字练习不上传首尾帧。复制同一条 A 镜头提示词，提交 **Generate**。页面当前说明为 **5 秒、480p**，这正好留下裁成 4 秒的余量。
3. 在结果区域预览并下载。沿用路线 A 的检查方法，将合格片段依次保存为 `A.mp4` 至 `D.mp4`。
4. 如果用自有封面，先准备相同比例的开始图和结束图，再填入 **Start Frame / End Frame**。用构图接近的两张图做小幅变化；第一遍不要同时要求换人物、换场景和转镜头。
5. 音乐在剪辑软件里加入。这个短片入口不等于“上传整首歌后自动剪完音乐视频”，演唱需求请走下面的音频与人像路线。

页面说明核对于 **2026-09-23**：[MusicMaker 短片用法及规格](https://musicmaker.im/free-short-music-video-generator/)。生成前查看当前可用额度和设置。

### 每做完一个镜头，先过这三关

| 看到的问题 | 先改什么 | 合格后再继续 |
|---|---|---|
| 一段里突然换车厢、灯光或天气 | 删掉场景切换，只保留一个地点、一种运镜 | 连续播放，没有跳变 |
| 雨滴、倒影、窗框混成一片 | 去掉多余动作，缩小运动幅度 | 主体轮廓能辨认 |
| 画面好看但下一镜头像另一个故事 | 在下一条重复同一地点、颜色与时间设定 | 四段并排看属于同一组画面 |

**不用生成也能练剪辑：** 下载[原创概念图](../assets/music-video-directions.png)，新建 16:9 横屏项目，把静态图铺满 16 秒，再加入音乐。它不是生成动画。要改做品牌作品衍生的画面，可先选[六个带图提案](brand-projects.zh-CN.md)，再沿用本页的生成与剪辑步骤。

## 3. 放到剪辑时间轴

使用能分别放入视频和音频、添加文字并导出的软件即可。没有现成软件时，可以选择免费开源的桌面剪辑软件 [Shotcut](https://www.shotcut.org/)，[官方教程](https://www.shotcut.org/tutorials/)介绍了界面和基础操作。不同软件的按钮名称有差异，下面按实际操作目标说明。

1. 新建项目：竖屏画面选 9:16；静态概念图练习选 16:9。
2. 导入音乐和画面，把音乐放在音频轨最开始的位置。
3. 第一段画面从 0 秒开始，末尾裁到 4 秒。
4. 第二、三、四段分别放在第 4、8、12 秒，每段保留 4 秒，最后在第 16 秒结束。不要留黑屏空隙。
5. 关闭四段视频自带的声音，只留练习音乐。先保持正常音量，不要一味调大。
6. 在最后一段加入片名，文字避开边缘，留足阅读时间。
7. 可选：导入[字幕文件](../starter-kit/practice-captions.srt)。它只在第 12—16 秒显示片名“LAST TRAIN HOME”，不是演唱歌词。制作自己的作品时，把片名替换成你的标题。不支持导入字幕时，按里面的时间手动添加文字。

| 时间 | 画面 | 作用 |
|---|---|---|
| 0—4 秒 | 车厢全景 | 交代场景 |
| 4—8 秒 | 窗上雨滴 | 增加细节 |
| 8—12 秒 | 台灯倒影 | 改变构图 |
| 12—16 秒 | 回到全景，加片名 | 完成收尾 |

### 使用 Shotcut 时

在 Timeline（时间轴）菜单中分别添加视频轨和音频轨，把画面和 WAV 音乐分开放入。选中最后一个镜头，添加 **Text: Simple**（简单文字）滤镜即可做片名。保存项目是为了以后继续修改；需要可播放的成片时，使用 **File → Export → Video**（文件 → 导出 → 视频）。操作说明见[官方常见问题](https://www.shotcut.org/FAQ/)。

## 4. 检查导出文件

先戴耳机看一遍，再用手机外放看一遍。检查切换时有没有黑屏、声音是否重叠、文字是否清楚、结尾是否突然截断。

软件支持时，可用 MP4 格式、H.264 视频编码和 AAC 音频编码导出初稿。保持素材原有帧率；低分辨率素材导出成大尺寸也不会恢复原本没有的细节。不要只看剪辑软件里的预览，要打开导出的文件完整播放一次。

本仓库提供音乐和制作方法，没有替你生成这四段视频。实际效果取决于工具输出和剪辑；出现问题时，先改有问题的那个镜头。

## 5. 换成自己的音乐

挑一段情绪完整的乐句，先听出重点，再把切点重新对齐。自己的歌不一定是每分钟 120 拍，不要直接照抄练习的时间格。另存一个项目，保留原来的练习版本。

正式发布前确认歌曲、图片和人物肖像的使用范围。[MusicMaker 商业许可](https://musicmaker.im/commercial-license/)对付费订阅与免费试用有不同规定；在 Discover 能听到一首歌，不代表你已获得再发布授权。

## 6. 换成人物演唱：一张图、一段歌声

下面以 MusicMaker 已公开的吉他弹唱为参考。**图片是官网的输入人像，点击观看对应成片。** 新练习请准备你有权使用的人像和歌曲，不直接把展示素材当作素材包。

<a href="https://cdn.musicmaker.im/musicmaker/ai_music_video_generator/example/example1_video.mp4"><img src="https://cdn.musicmaker.im/musicmaker/ai_music_video_generator/example/example1_cover.webp" alt="暖光下持吉他的女子，这是 MusicMaker 演唱示例的输入人像；点击播放原视频" width="640"></a>

先截取自己歌曲里 **5—10 秒的完整演唱短句**，避免从半个字开始。准备一张脸部清晰、嘴部无遮挡、人物比例合适的图片。先只做一个镜头；不用一开始就安排弹琴、走路、转身和多个机位。

**官方路线：** 在 [Hailuo H3](https://hailuoai.video/zh-Intl/tools/minimax-h3) 使用 **Omni Reference**（多素材参考），同时提供人物图和音频。在描述中明确哪份文件决定人物、哪份文件提供歌声；按实际上传后的素材标记引用它们。若当前账户没有音频参考控件，不要用文字提示假装替代音频输入。

**MusicMaker 路线：** 打开[音乐视频工具](https://musicmaker.im/ai-music-video-generator/)，在 **Music File** 放入同一段歌声，在 **Character Image** 放入人物图，在 **Prompt** 填动作描述。提交前检查页面的 **Public** 公开开关和本次消耗估算，再生成并预览。

可复制的原创练习提示词（不是官网原作提示词，尚未实测生成）：

```text
使用上传的人物图确定歌手外貌，用上传的音频作为演唱时间参考。
暖色舞台，固定中近景，保持服装、麦克风和背景一致。
歌手面向镜头，轻微点头并自然演唱，不转身、不换镜头。
保持嘴部无遮挡，手部只做很小的动作。不要添加文字。
```

**检查顺序：** 先听导出视频是否仍对应所选乐句，再看句首、句中、句尾的嘴形；随后检查牙齿、手指、麦克风是否变形。若音频被改写，不要直接替换成原曲并宣称对嘴成功；先缩短片段或重做，再核对。剪入最终作品前保证音轨不重叠。

想继续做吉他或近景演唱，进入[品牌图文提案](brand-projects.zh-CN.md#performance-1)。需要回到无人物的环境镜头，就用第 2 节的任一入口。
