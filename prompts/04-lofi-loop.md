# 04 · Last train home

**Level:** Easy · **Editing target:** 8-second visual loop · **Status:** original brief, not render-tested.

## Bring these inputs

An instrumental track; no face reference is needed.

**Starting route:** [Short Music Video Generator](https://musicmaker.im/free-short-music-video-generator/). Use only input modes and durations currently offered by the tool. Longer plans require separate clips and editing.

## Image direction

Use this to create or choose a reference image. For text-to-video, the motion prompt can be used without an image when the tool permits it.

```text
Empty night train carriage with teal fabric seats, amber reading lamp, rain on a large window and distant city lights. Textured illustration, quiet night mood, no text.
```

## Copy the motion prompt

```text
An empty night train carriage, teal fabric seats, a small amber reading lamp and rain on the window. Locked camera. Only rain and distant outside lights move gently. Seats, lamp and framing remain unchanged. No people, no lettering, no cuts.
```

## Music direction

For an original song or instrumental; skip this if you already have audio.

```text
Soft instrumental: muted keys, rounded bass, dry kick and snare, gentle offbeat percussion, no vocals. Use a sparse arrangement to leave room for the scene.
```

## Assemble the edit

Make two short views, trim to four seconds each, and return to the first composition. Test two repetitions. Match the seam by trimming or a brief dissolve; do not assume the prompt makes a seamless loop. For the 16-second kit, use its four-shot plan instead.

## If it fails

If it jumps, remove the camera movement and regenerate only the problem view. Do not reverse rain footage to fake a loop.

**Before you export:** Seats do not breathe or bend; the visual seam is unobtrusive across two consecutive repeats.

Change one variable per retry and keep your best take. Use the [brief template](../starter-kit/brief-template.md) to record the actual inputs, output settings, and changes.
