# 01 · Living album cover

[All recipes](README.md) · [Home](../README.md) · [Editing help](../docs/editing.md)

**Level:** Easy · **Editing target:** 8 seconds · **Status:** original brief, not render-tested.

## Bring these inputs

Your own cover art; a music excerpt you may use.

**Starting route:** [Short Music Video Generator](https://musicmaker.im/free-short-music-video-generator/). Use only input modes and durations currently offered by the tool. Longer plans require separate clips and editing.

## Image direction

Use this to create or choose a reference image. For text-to-video, the motion prompt can be used without an image when the tool permits it.

```text
Square cover image: one translucent amber glass flower on charcoal stone, side lighting, large quiet background, tactile grain, no lettering.
```

## Copy the motion prompt

```text
Preserve the reference composition and the exact glass flower shape. A soft band of light travels slowly across the petals while tiny dust particles drift. Locked camera, still pedestal, no new objects, no text, no cuts.
```

## Music direction

For an original song or instrumental; skip this if you already have audio.

```text
Warm instrumental: soft electric piano, restrained bass, dry drums, a short memorable motif. Ask for an instrumental rather than a celebrity sound-alike.
```

## Assemble the edit

Generate two supported short takes. Pick the strongest four seconds of each for an eight-second edit. Keep the same music continuous; put the title on a separate text layer.

## If it fails

If the flower deforms, remove dust and ask only for a lighting change. If cover lettering warps, animate a clean image and overlay the original typography afterward.

**Before you export:** The cover is recognizable before and after the movement; no extra petals appear.

Change one variable per retry and keep your best take. Use the [brief template](../starter-kit/brief-template.md) to record the actual inputs, output settings, and changes.
