# 08 · Rooftop afterglow

[All recipes](README.md) · [Home](../README.md) · [Editing help](../docs/editing.md)

**Level:** Easy · **Editing target:** 16 seconds · **Status:** original brief, not render-tested.

## Bring these inputs

Your indie/pop track and an authorized artist silhouette or original fictional performer.

**Starting route:** [Short Music Video Generator](https://musicmaker.im/free-short-music-video-generator/). Use only input modes and durations currently offered by the tool. Longer plans require separate clips and editing.

## Image direction

Use this to create or choose a reference image. For text-to-video, the motion prompt can be used without an image when the tool permits it.

```text
A lone adult performer seen from behind on a small rooftop at blue hour, terracotta jacket, warm string lights, soft city horizon, cinematic grain, no text.
```

## Copy the motion prompt

```text
The performer faces the city, seen from behind. A light breeze moves the edge of the terracotta jacket. Slow gentle push toward the horizon. Keep the same body shape, jacket and rooftop. No visible singing mouth, no new people, no sudden turns.
```

Use the same reference image or reference sheet when supported. Each block below is a complete prompt for **one separate generation**. Timings describe the edit, not the generation request; generate a supported length and trim it.

## Music direction

For an original song or instrumental; skip this if you already have audio.

```text
Indie pop: warm guitar, restrained drums, rounded bass and a hopeful chorus. Choose a phrase with an audible ending rather than stopping mid-word.
```

## Assemble the edit

Use four four-second shots: wide silhouette, string lights, jacket detail, return to wide. Keep skyline direction and light consistent. Let the final shot breathe instead of adding another cut.

## If it fails

If the person turns unexpectedly, lock the back-facing pose. If the skyline jumps, retain one reference and use closer detail shots between wide views.

**Before you export:** The performer stays recognizable and the city feels like the same place across all four shots.

Change one variable per retry and keep your best take. Use the [brief template](../starter-kit/brief-template.md) to record the actual inputs, output settings, and changes.
