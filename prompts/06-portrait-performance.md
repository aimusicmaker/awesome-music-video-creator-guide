# 06 · Portrait performance

[All recipes](README.md) · [Home](../README.md) · [Editing help](../docs/editing.md)

**Level:** Intermediate · **Editing target:** A short vocal excerpt supported by the live tool · **Status:** original brief, not render-tested.

## Bring these inputs

One authorized adult portrait and your vocal audio; choose a short phrase.

**Starting route:** [AI Music Video Generator](https://musicmaker.im/ai-music-video-generator/). Use only input modes and durations currently offered by the tool. Longer plans require separate clips and editing.

## Image direction

Use this to create or choose a reference image. For text-to-video, the motion prompt can be used without an image when the tool permits it.

```text
Chest-up portrait of an original adult vocalist in a plain rust-colored shirt, clear unobstructed face, relaxed shoulders, soft studio lighting, simple dark background, no mic blocking the mouth.
```

## Copy the motion prompt

```text
Keep the supplied person recognizable, with unchanged face, hairstyle, clothing and background. Restrained performance, minimal head movement and relaxed shoulders. Steady chest-up framing. No cuts, no extra people, no dramatic gestures.
```

## Music direction

For an original song or instrumental; skip this if you already have audio.

```text
Use an existing authorized vocal phrase. If creating one, ask for an original gentle melody with clear syllables and minimal overlapping vocals. Do not clone a real performer without permission.
```

## Assemble the edit

Use the music-video audio/image route. Upload the actual vocal excerpt and portrait; paste only the motion prompt, review the Public setting and credit estimate, then test. Inspect mouth timing on prominent consonants. Use a separate editor to combine usable takes.

## If it fails

If synchronization fails, simplify head motion, shorten the phrase, or use a portrait visual without showing a singing mouth. A prompt cannot fix every alignment error.

**Before you export:** Face identity stays stable and the mouth does not visibly lag the vocal. Label an unsynchronized result as a portrait visual, not a lip-sync demo.

Change one variable per retry and keep your best take. Use the [brief template](../starter-kit/brief-template.md) to record the actual inputs, output settings, and changes.
