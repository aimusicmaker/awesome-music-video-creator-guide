# 12 · Full-song storyboard

[All recipes](README.md) · [Home](../README.md) · [Editing help](../docs/editing.md)

**Level:** Advanced · **Editing target:** Your song’s actual duration · **Status:** original brief, not render-tested.

## Bring these inputs

A finished song, its section timings, reference sheet, and generation budget.

**Starting route:** [Short Music Video Generator](https://musicmaker.im/free-short-music-video-generator/). Use only input modes and durations currently offered by the tool. Longer plans require separate clips and editing.

## Image direction

Use this to create or choose a reference image. For text-to-video, the motion prompt can be used without an image when the tool permits it.

```text
Build a reference sheet for one original world: empty seaside station, teal benches, amber platform lamp, coral suitcase. Keep these props and colors for all sections.
```

## Copy the motion prompt

```text
An empty seaside station at dusk with teal benches, amber platform lamp and one coral suitcase. Gentle sea mist moves in the background. Slow lateral camera drift, stable architecture and suitcase, no people, no readable signs, no cuts.
```

## Music direction

For an original song or instrumental; skip this if you already have audio.

```text
Use the finished track as the timing source. Do not generate visuals before choosing the actual mix: different intros and chorus lengths change the shot plan.
```

## Assemble the edit

Mark verse, pre-chorus, chorus, bridge and outro in the editor. Plan one shot per musical phrase, then count the required supported clips. Produce three test shots before expanding. Use wider views for the chorus, details for quieter passages, and return to the original suitcase in the outro.

## If it fails

If costs grow, reuse a strong shot with a considered crop or hold an image through a quieter phrase. If continuity fails, reduce the number of locations rather than rewriting every prompt.

**Before you export:** The full export covers the actual song with no gaps; recurring places and props make the sections feel related.

Change one variable per retry and keep your best take. Use the [brief template](../starter-kit/brief-template.md) to record the actual inputs, output settings, and changes.
