# 09 · Open-road diary

[All recipes](README.md) · [Home](../README.md) · [Editing help](../docs/editing.md)

**Level:** Easy · **Editing target:** 20 seconds · **Status:** original brief, not render-tested.

## Bring these inputs

Travel photos you can use; a song excerpt; no footage shot while you are driving.

**Starting route:** [Short Music Video Generator](https://musicmaker.im/free-short-music-video-generator/). Use only input modes and durations currently offered by the tool. Longer plans require separate clips and editing.

## Image direction

Use this to create or choose a reference image. For text-to-video, the motion prompt can be used without an image when the tool permits it.

```text
Sunlit road seen from the passenger seat, distant hills, warm late-afternoon light, understated documentary texture, no road signs with legible text.
```

## Copy the motion prompt

```text
View from a passenger seat through the side window. Sunlit hills pass slowly outside. Keep the interior edge fixed and the horizon stable. Natural motion, gentle reflections, no abrupt acceleration, no visible driver or text.
```

## Copy one prompt per shot

Use the same reference image or reference sheet when supported. Each block below is a complete prompt for **one separate generation**. Timings describe the edit, not the generation request; generate a supported length and trim it.

## Music direction

For an original song or instrumental; skip this if you already have audio.

```text
Acoustic travel instrumental: strummed guitar, light hand percussion and a relaxed bass line, a small melodic lift in the middle. Avoid prescribing an exact output duration unless supported.
```

## Assemble the edit

Make five separate four-second images or clips: departure bag, road, landscape, arrival detail, wide destination. Add location labels in the editor only if accurate. Cut to musical phrases.

## If it fails

If landscapes race past or smear, reduce speed. If locations disagree, present the shots as a travel montage instead of pretending they are one continuous road.

**Before you export:** The sequence has a departure and arrival; no invented location label is presented as factual.

Change one variable per retry and keep your best take. Use the [brief template](../starter-kit/brief-template.md) to record the actual inputs, output settings, and changes.
