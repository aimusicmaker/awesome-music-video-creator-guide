An electronic track with a clear transition; an original ring image.

## Image direction

Use this to create or choose a reference image. For text-to-video, the motion prompt can be used without an image when the tool permits it.

```text
One liquid-chrome ring above still black water, icy blue reflections and a small magenta rim light, centered composition, no typography.
```

## Copy the motion prompt

```text
Preserve one chrome ring and the black water setting. The ring rotates very slowly around its vertical axis. Reflections move continuously with the ring. Fixed camera, constant silhouette, no extra rings, no cuts or text.
```

Use the same reference image or reference sheet when supported. Each block below is a complete prompt for **one separate generation**. Timings describe the edit, not the generation request; generate a supported length and trim it.

## Music direction

For an original song or instrumental; skip this if you already have audio.

```text
Electronic instrumental: steady kick, pulsing bass, restrained percussion, a rising texture before a clear change. Pick the excerpt after listening; a BPM request is not a measured output tempo.
```

## Assemble the edit

Generate two calm takes and two brighter takes using the two shot prompts above. Trim each to four seconds for a 16-second sequence. Put the calm takes at 0:00 and 0:04, and the brighter takes at 0:08 and 0:12 for the practice beat. With your own song, move the change to its marked musical event. Create any actual audio-reactive scale or glow in the editor.

## If it fails

If the ring melts uncontrollably, replace liquid motion with rigid rotation. If flashes are distracting, use one gradual color change rather than rapid flicker.

**Before you export:** The shape stays identifiable; any claimed beat-reactive motion is actually aligned in the final edit.

Change one variable per retry and keep your best take. Use the [brief template](../starter-kit/brief-template.md) to record the actual inputs, output settings, and changes.
