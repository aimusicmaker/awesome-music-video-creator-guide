# 02 · Four-shot release teaser

[All recipes](README.md) · [Home](../README.md) · [Editing help](../docs/editing.md)

**Level:** Easy · **Editing target:** 16 seconds · **Status:** original brief, not render-tested.

## Bring these inputs

A finished chorus or the included practice beat; an original visual motif.

**Starting route:** [Short Music Video Generator](https://musicmaker.im/free-short-music-video-generator/). Use only input modes and durations currently offered by the tool. Longer plans require separate clips and editing.

## Image direction

Use this to create or choose a reference image. For text-to-video, the motion prompt can be used without an image when the tool permits it.

```text
A closed coral envelope on a dark teal desk beside a small amber lamp, close framing, shallow depth, no handwriting or logos.
```

## Copy the motion prompt

```text
A single coral envelope lies on a teal desk under an amber lamp. The camera moves slowly closer. The envelope remains closed and rigid; light shifts gently across the paper. No hands, no text, no additional objects.
```

## Copy one prompt per shot

Use the same reference image or reference sheet when supported. Each block below is a complete prompt for **one separate generation**. Timings describe the edit, not the generation request; generate a supported length and trim it.

<details>
<summary>0–4s · Envelope wide</summary>

```text
A single closed coral envelope on a dark teal desk beside a small amber lamp. Slow camera push toward the envelope. Keep the envelope closed and rigid, with no hands, writing, or new objects.
```

</details>

<details>
<summary>4–8s · Paper texture</summary>

```text
Close view of the paper texture on the same closed coral envelope on the dark teal desk. Soft amber lamplight travels gently across the surface. Locked camera, stable paper edges, no hands, no writing, no new objects.
```

</details>

<details>
<summary>8–12s · Lamp reflection</summary>

```text
Close view of the amber lamp reflected in the polished dark teal desk beside the same closed coral envelope. Only the reflection glows gently. Fixed camera, unchanged desk and envelope, no people or lettering.
```

</details>

<details>
<summary>12–16s · Return wide</summary>

```text
Return to the original wide view of one closed coral envelope on a dark teal desk beside a small amber lamp. Hold the camera still. Keep the upper background quiet for an editor-added title. No generated text, no hands, no opening envelope.
```

</details>

## Music direction

For an original song or instrumental; skip this if you already have audio.

```text
Bright indie pop: clean rhythmic guitar, warm bass, crisp snare, one chorus melody. Arrange a clear lift rather than a long ambient introduction.
```

## Assemble the edit

Make separate shots: envelope wide, paper texture, lamp reflection, envelope wide. Use four seconds each at 0/4/8/12 seconds for the practice beat. Add your release title on the last shot.

## If it fails

If a generated hand appears, restate “empty desk, no people or hands.” If the first shot feels slow, begin closer to the envelope instead of adding frantic cuts.

**Before you export:** The hook appears immediately; the final title remains readable for at least the intended final hold.

Change one variable per retry and keep your best take. Use the [brief template](../starter-kit/brief-template.md) to record the actual inputs, output settings, and changes.
