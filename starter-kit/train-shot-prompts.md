# Four train-shot prompts

[English walkthrough](../docs/first-video.md) · [中文教程](../docs/first-video.zh-CN.md)

Generate each block separately with 9:16 selected. Make a supported short clip, then trim each to four seconds. Keep the best wide view as a visual reference where the tool supports one. These are untested generation briefs; the included MP4 is a separate still-image editing demonstration.

每个代码块单独生成一段，选择 9:16 竖屏，再各取 4 秒。四段依次是全景、雨滴、倒影、回到全景。工具支持参考图时，复用同一场景图片。以下提示词尚未实测；练习包里的 MP4 是另行制作的静态图剪辑示例。

## A · 0–4 seconds · Wide carriage

```text
An empty night train carriage with teal fabric seats, an amber reading lamp and rain on the window. Distant city lights drift slowly outside. Locked wide camera; seats and lamp remain still. Textured painted illustration, intimate night mood, vertical frame, no people, lettering or cuts.
```

## B · 4–8 seconds · Rain detail

```text
Close view of rain sliding down the window in the same empty night train. A small edge of the teal seat remains visible; distant city lights are softly blurred, with warm amber reflections from the reading lamp. Locked camera, same painted style, vertical frame. No people, lettering or cuts.
```

## C · 8–12 seconds · Lamp reflection

```text
Close view of the amber reading lamp reflected in the rainy window of the same empty night train. Teal upholstery is visible at the frame edge. Only the rain and distant outside city lights move. Fixed camera, same textured painted style, vertical frame, no people, lettering or cuts.
```

## D · 12–16 seconds · Return wide

```text
Return to the wide view of the same empty night train, teal fabric seats, amber reading lamp and rainy window with distant city lights. Locked camera; seats and lamp remain still while rain moves gently. Same painted style, vertical frame. Leave quiet space for an editor-added title. No people, generated lettering or cuts.
```
